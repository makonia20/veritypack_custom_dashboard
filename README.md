# VerityPack Custom Dashboard (App Switcher)

A modern, standalone fullscreen application launcher for Odoo 19 that replaces the default small app dropdown with a dark glassmorphic grid overlay.

## Features
- **Fullscreen App Launcher**: Seamless fullscreen overlay displaying all installed applications as rounded cards.
- **Modern Dark Glassmorphism**: High-performance CSS styling with backdrop blur and hover micro-animations.
- **Keyboard & Touch Friendly**: Esc key / overlay background click to close, responsive grid layout for desktop, tablets, and mobile.
- **Universal Compatibility**: Works on any Odoo 19 instance without external dependencies.

## Installation
1. Place this directory inside your Odoo custom-addons folder.
2. Update your apps list.
3. Install **VerityPack Custom Apps Dashboard**.
